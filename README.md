PakCalc: Free Online Calculators for Pakistan
PakCalc is a simple, fast and free website with everyday money calculators made for people in Pakistan.
Live site: (https://bucolic-lamington-e7d903.netlify.app/)
Salary Tax Calculator (FY 2026-27)
Zakat Calculator
EMI / Loan Calculator
More tools coming soon
Features
Free to use, no hidden charges
Works on mobile and desktop (responsive design)
Your inputs stay in your browser, nothing is sent to a server
Every field has an example to guide you
Tips below each result to help you understand the numbers
Built With
HTML
CSS
JavaScript (vanilla, no frameworks)

Download or clone this repository:
git clone https://github.com/salishba692-bot/calculate.git
Open the folder
Double-click index.html to open it in your browser
No installation needed.
